# WebDAV 工作区

## 连接

1. 用 `npm start` 或BAT运行本机服务。若升级时服务已运行，需要先结束旧服务再重启，单纯刷新页面不会加载新的后端接口。
2. 文件 → 连接 WebDAV，或设置 → 通用 → 工作区。
3. 地址留空默认 `https://dav.jianguoyun.com/dav/Typora/`（坚果云）。目录名称区分大小写；如果你的目录实际是 `typora`，请按远端真实名称修改。填写账号及第三方应用密码，不是账户登录密码；其它服务填写完整目录地址，不是网盘分享页面。
4. 优先HTTPS。HTTP明文传输文件和凭据，表单要求显式确认。证书错误不会静默忽略，重定向不自动跟随，请填写最终地址。
5. 连接成功后从文件树编辑。源文件写回该远端目录，图片可写入文档同名 `.assets/`。
   只需要某个子目录时可直接填写 `https://dav.jianguoyun.com/dav/typora/`，末尾斜杠可省略，目录名须与远端实际大小写一致。此连接只扫描typora内部，不扫描网盘根目录其它应用文件夹。修改已授权根地址为子目录时，可留空密码，复用同账号已保存凭据或当前会话；不向其它站点、上级或兄弟目录复用。404代表路径不存在，不是“不支持子目录”。
6. 密码右侧眼睛按钮控制显示/隐藏。“保存密码”启用Windows当前用户DPAPI加密保存；“自动登录与重连”依赖保存密码。取消勾选保存密码会立即删除持久化凭据并关闭自动登录，不必再次点击连接；清除失败会恢复勾选并提示。当前表单已输入的密码只留在表单内，关闭即清空。底部只保留断开连接、连接；主动断开也会关闭自动登录。

## 坚果云与503

坚果云官方说明免费账户每30分钟600次请求、付费账户1500次；单目录返回条目有750上限。参见[官方限制](https://help.jianguoyun.com/?p=2064)。503也可能是暂时服务故障，不能仅凭状态码认定密码错误或已超额。

R65改为按层加载，替代R64递归扫描与固定3.1秒间隔：

- 连接时加载根目录各页，只读名称与类型。显示根目录后，串行预取根目录直接子文件夹的内容，不继续向深处递归；`.assets` 不参与文件树预取。
- 展开一个文件夹时复用已加载内容，未加载则先补全，再预取它直接子文件夹中的条目。折叠或切换工作区后不继续该批预取；进入后台后不发起下一项。预取失败就停止，手动展开可重试。
- 分页按照响应头 `Link: <...>; rel="next"`，参考[坚果云官方插件实现](https://github.com/nutstore/obsidian-nutstore-sync/blob/main/src/api/webdav.ts)。只允许同源、同目录的下一页，拒绝循环和越界。页面短缓存60秒；子目录已成功加载的页面在本次工作区复用，失败后从未完成页继续。文件数标记“已加载”，不是网盘总数；搜索当前只包含已加载文件。
- 打开文件才GET正文，恢复最后文档时只补加载它的祖先目录；读取已知路径不再逐层stat。保存只处理明确修改/新增的文件，未加载目录不是删除清单。条件写入和写后核对仍保留。

请求预算默认按免费版保守设置：同一个本机服务进程中，同账号共享30分钟滚动记录。普通读取达到480次暂停，后台目录预取最多60次（包含在480内）；总预算540次，额外额度留给保存及写后读取校验。最小发送间隔150毫秒，允许短时打开操作，不必每个请求固定等待3.1秒。自动保存仍合并1.5秒内连续编辑。到预算会返回可重试时间，不无限排队或循环重连。

预算不是坚果云服务器实际剩余额度：重启服务会重置本地计数，另一个本机服务进程、坚果云客户端和其他设备都会另行消耗同账号额度。付费账号当前也使用上述保守预算，尚无账户套餐选项。不能承诺完全避免上游限流。

## 多图文档

远端相对图片地址在渲染阶段先保持为不可请求的占位数据。近可见区域250px的图片优先；可见光标或当前阅读位置前后各5张提前读取，滚动时窗口随阅读位置移动，包括未挂载DOM的图片。应用最多同时调度10项；HTTP/1.1浏览器、网络及坚果云限制可能使实际并发更少，本机夹具实测峰值6。隐藏预览不会把全部图片提前下载，仅源码视图不预取。按文档相对路径直接GET图片，不必先列出或stat每层图片目录。图片地址仍是相对 `.assets` 路径，不把传输用的base64或显示用的blob地址写入正文。

正式后端使用服务端磁盘缓存。同工作区复用页面已读地址，同一服务的同账号/完整工作区端点可复用磁盘图片；不同账号/端点隔离，不以会话令牌作为永久键。默认用户目录 `.writide/image-cache/`，可用WRITIDE_CACHE_DIR指定专用目录；旧INKQUAY_CACHE_DIR仍作为兼容别名。默认1 GiB/5000项、检查间隔30分钟。缓存图片不加密，磁盘权限与备份需按私人资料处理；不要让多个服务进程共用同一个缓存目录。

已读图片以原始字节落盘，索引记录自然尺寸、原始ETag、时间、大小和本机完整性摘要。重开编辑器前批量读本机尺寸，不发逐图HEAD。缓存到期后的下一次读取才分页检查实际资源目录，ETag与大小一致复用；变化、缺少验证器或缓存损坏则GET。目录页合并并发检查，不按父目录mtime猜测子文件变化。普通Markdown保存不会清空所有图片缓存，写入对应图片才失效该图片。

设置 → 缓存与网络提供开关、容量、检查间隔、检查更新、清理，以及本次服务命中/下载请求快照。手动更新当前图片，仍保留原MD和原路径，不PUT正文。清理缓存不删除远端文件/凭据，保留当前页已显示图片；重开后按需重新取图。设置/容量作用于该服务，不是当前手机设备。

缓存检查失败时允许显示旧缓存并提示“未完成版本检查”；401/403/404不掩盖。缓存目录不可写时仍允许在线读取，但明确提示未落盘。检查间隔是按需新鲜度策略，不是一直轮询网盘；页面已经持有的图片地址要手动检查更新或重开才会刷新。缓存不是离线草稿，仍需在线建立有效工作区会话，未增加整库下载或手机离线启动。

600张互不相同且未缓存的图片，若全部查看，图片本身通常就需要600次GET，再加目录、正文和保存请求，免费额度确实可能不够。本应用不会在打开时全取，也不会“卡死”等待所有图片；预算耗尽时已加载正文仍可阅读，未加载图片等待额度恢复。懒加载减少未看的请求，不能把实际看完600张图片变成零成本。首次加载前未知图片最终高度，仍沿用已有滚动位置保护，不承诺全文高度提前固定。

遇503/429读取Retry-After，缺失时30秒开始递增冷却；冷却内不继续请求同一账号。启用自动登录后最多连续尝试3次；返回前台/恢复网络可再次触发恢复，但仍遵守冷却。不会为了重连清空文档，也不会偷偷放弃原ETag去覆盖远端版本。服务端仍处于限流窗口时必须等待，不能立即修复上游503。

## 已交付范围

基本认证/无认证、目录枚举、Markdown/文本读取、修改与新增、目录新增、图片二进制读写。标准服务利用强ETag与If-Match避免覆盖已经变化的文件；坚果云使用其原样返回的opaque ETag执行同等条件保存，新文件用If-None-Match防止覆盖同名文件。

支持同目录文档重命名：标签双击或文件右键改名，先保存未提交内容，再发送If-Match与Overwrite:F的MOVE，成功后读取新路径核对。拖动文档到其它远端文件夹时，Writide 会先复制并按字节校验正文引用的同级 `.assets` 目录或同级图片，再条件 MOVE 文档；源附件暂时保留，避免破坏其它文档的共享引用。服务不支持MOVE、目标碰撞、父级相对资源或版本变化时会明确拒绝，不自动重试不确定的移动。

仍不支持远端删除、文件夹移动/重命名、文件锁、Digest/OAuth、离线同步和跨设备实时协作。对应操作会拒绝，不应另存到服务器Workspace。跨目录文档移动不是多资源原子事务，网络中断后应重连核对源与目标。单文件/目录响应仍限制20MiB；非常大的目录仍建议按笔记子目录连接。文件树不是持续实时同步，远端外部变更需重连后重新读取，保存时由ETag拒绝冲突。

## 保存失败

- “保存冲突”：其它客户端修改了该文件。远端不被覆盖，本地内容留在编辑器。先导出当前Markdown，再重新连接读取远端，人工合并。
- “没有可用于条件保存的ETag”：该服务无法按当前安全策略更新已有文件；不提供强制覆盖按钮。坚果云不带引号的opaque ETag已单独兼容并实测旧版本返回412，其它非标准格式仍拒绝。可新增文件，或使用支持条件写入的服务。
- 网络/凭据失效：不切换为本地副本，不丢弃当前编辑内容；恢复网络后可重试保存。刷新前请导出未保存修改。
- 服务不支持标准方法或地址错误：连接失败保留原工作区，表单内显示错误。

## 会话与安全

默认密码只在本机Node进程内存。显式选择保存后，连接资料整体加密存放于当前Windows用户目录 `.writide/webdav.dpapi`，不在项目、Git或localStorage中；仅同一Windows账户可正常解密，不能防御已经控制该账户的恶意程序。其它系统暂不支持持久化密码，会明确拒绝，不退化为明文。

浏览器只保存URL、用户名及不透明会话令牌。启用自动登录后第二个同源标签页、重新打开浏览器和服务重启可使用已保存凭据恢复；未启用则需手动连接。授权令牌失效只刷新一次；会话恢复后保留已读版本和未保存文本。没有独立离线草稿库，失败时不要刷新丢弃未保存内容，先导出。

取消保存密码不等于退出当前登录：当前标签页会话仍能读写，切后台再回来也可继续。新标签页不能据此自动登录；主动断开、会话真实过期或服务重启后，已经删除的持久化密码无法再用于恢复。

桥接API仅接受本机同源请求和随机操作令牌；允许用户指定局域网NAS地址，不是公共任意URL代理。不要把本机服务反向代理到公网，不要向不可信页面共享会话令牌。断开连接会移除服务器内存会话；未保存时要求先处理当前修改。

协议库：[webdav-client 官方项目](https://github.com/perry-mitchell/webdav-client)。自动验证主要使用隔离HTTP服务；以下为另行授权的真实只读抽样，不声明所有厂商兼容。

## 2026-09-11只读实测

按用户授权，使用当前Windows用户已保存的加密凭据，仅访问已连接笔记子树中一个指定教程的.assets目录及一张抽样PNG。不读取其他应用目录，不保存凭据到代码/日志，不修改远端。共8次HTTP请求：3次PROPFIND、1次HEAD、4次条件GET；GET若返回200仅观察响应头后取消响应体，没有全文/全库下载。

| 检查 | 真实结果 | 结论 |
| --- | --- | --- |
| Depth1同时请求resourcetype/getetag/getlastmodified/getcontentlength | 207；52张PNG全部带ETag、mtime和size；无后续页 | 可利用该资产目录的逐文件元数据批量判断，不能推广为所有路径都一致 |
| 重复相同属性请求 | 抽样ETag、mtime、size与首次一致 | 未修改样本在本轮保持相同版本；没有测试外部修改后的ETag变化 |
| 同一PNG的HEAD | 200，无ETag，Content-Length为0，带Last-Modified | 不能依赖HEAD给图片版本或真实大小，也不能从大小推算尺寸 |
| GET If-None-Match原样返回的ETag | 304，ETag与目录匹配 | 该样本支持原值条件缓存 |
| 同一ETag人为加双引号 | 200 | 服务返回值无引号，不能擅自格式化再发；与标准HTTP ETag格式有差异 |
| GET If-Modified-Since目录返回时间 | 200 | 本次时间条件没有避免正文响应，不把它当可靠省请求路径 |

另一次目录探测仅请求etag/mtime/size、未包含resourcetype时未返回etag；由此发出的缺失值条件请求不纳入ETag支持结论。后续实现应保留已经验证的属性组合，并覆盖属性缺失/多propstat情形。

推荐优先采用本地持久化缓存+资源目录版本快照，图片变化少时设置较长且可见的检查间隔，提供主动刷新。ETag是版本标识，不保证MD5或SHA；本地hash不能独自证明远端未变。[ETag定义](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/ETag)

R70实测时磁盘缓存尚未实现；R72已落地磁盘缓存、目录增量检查和默认30分钟按需校验选项。R87使用随机临时Markdown文件验证坚果云未加引号ETag：原样If-Match更新返回204，随后复用旧值返回412且内容未被覆盖，临时文件已删除。因此仅对 `dav.jianguoyun.com` 接受安全字符组成的opaque ETag；其它服务仍要求标准强ETag。仅凭图片响应也不认定所有Markdown文件的响应格式相同。
