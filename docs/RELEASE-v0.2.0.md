# Writide v0.2.0 预发布说明

`v0.2.0` 是第二个公开预览版本，重点是 WebDAV 文档移动、Windows 启停可靠性，以及面向 amd64 与 ARMv8 设备的 Docker 运行路径。

## 主要变化

- WebDAV 新连接默认进入坚果云 `Typora` 子目录；已有连接地址不会被改写。
- WebDAV 文档可拖入其它文件夹。移动前复制并校验文档引用的同级 `.assets` 目录或同级图片，源附件暂时保留以保护共享引用。
- Windows 启动器使用单个 Node 进程检查端口与服务身份，服务就绪后自动打开浏览器；停止脚本只处理当前项目实例。
- 新增生产静态服务、Basic 访问认证、精确 Origin/Host 校验、独立 `/data` 数据目录和健康检查。
- 新增 amd64/arm64 Dockerfile、Compose 配置、只读根文件系统、非 root 用户、资源上限及部署说明。
- GitHub 可按发行标签分别构建和启动检查两个架构，再发布统一 GHCR 多架构镜像，同时附加各架构离线归档。
- Docker不再要求预先创建 `.env`：默认账号 `admin`、默认密码 `password`，密码最低8个字符；设置新增“访问安全”，可在登录后修改并将认证摘要持久化到 `/data`。未显式配置Origin时使用请求自身的Host/Origin同源校验，容器不会再因缺少这两个环境变量反复重启。
- Docker/Linux新增AES-256-GCM WebDAV凭据库；勾选保存密码及自动登录后，容器重建可恢复连接。反向代理内部Host与外部Origin不一致时不再误拦同源写入，非JSON代理错误也会保留HTTP状态供排查。
- 坚果云返回不带双引号的opaque ETag；现仅对坚果云原样使用该版本值执行If-Match条件保存。真实临时文件验证首次更新成功、复用旧版本返回412且没有覆盖新内容，冲突保护不降级。

## 获取与运行

普通 Windows 本地使用请阅读根目录 `README.md`。Docker 用户请完整阅读 `docs/DOCKER.md`，不要只复制一条命令。

amd64 与 arm64 设备均可直接拉取 `ghcr.io/shiranzby/writide:0.2.0`，Docker 会自动选择架构。GitHub 自动生成的 Source code 压缩包是源码，不是 Docker 镜像；`linux-amd64` 与 `linux-arm64` 发行资产是无法连接 GHCR 时的离线备用，并各自提供 `.sha256` 文件。

## 已知限制

- 这是预发布版，先备份重要文档，在可信单用户环境试用。
- 默认密码是公开的部署初始值，首次登录后必须修改；它不适合直接暴露公网。
- 支持 amd64 和 64 位 ARMv8/AArch64，不支持 32 位 ARMv7。
- Basic 认证在纯 HTTP 下不会加密密码。跨机器访问应通过 HTTPS、VPN 或受信任内网，不要直接暴露公网端口。
- Docker凭据密钥与密文同在 `/data`，不保存明文，但整个数据卷泄露时仍应立即撤销WebDAV应用密码。
- 所有已认证浏览器共享服务端工作区与会话，不具备多用户隔离。
- WebDAV 文档与附件移动不是远端多文件原子事务；中断后请重新连接并核对目标。
- 首次未知尺寸的远端图片仍可能在加载后改变页面高度。

## 升级前

保存所有文档，备份 Docker `/data` 卷或本机 `Workspace`，再停止旧版本。不要使用 `docker compose down -v`，除非明确要删除数据卷。
